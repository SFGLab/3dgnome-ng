This page covers your own data, the results and running the engine on your own computer.
Input formats
Input files are plain text with one record per line, separated by tabs or spaces, with positions in base pairs on GRCh38. Each cell type on the server has a full set, and an upload replaces one file of the set.
File
Columns
Notes
Loop anchors, BED
chr start end orientation
Orientation of the CTCF motif, L, R or N. Use N when it is unknown and for RNAPII anchors. Give the orientation on every line or on none. The engine reads the first line to decide whether the file has it.
Loops, BEDPE
chr1 start1 end1 chr2 start2 end2 count
One file per factor, CTCF first. The count is the number of PETs. Loops between chromosomes are skipped, and a loop longer than 1 Mb goes to the coarse contact map.
Contacts, BEDPE
chr1 start1 end1 chr2 start2 end2 count
Hi-C bin pairs or ChIA-PET singletons, with an integer count. The start column gives the position of each end. An uploaded .hic or .mcool map is converted to this format.
Genes, GTF
standard GTF
Gene records give the gene name and the TSS, taken from the strand.
Enhancers, BED
chr start end
One enhancer per line, for example from EnhancerAtlas.
Segment split, BED
chr position position
Optional. Positions where the coarse segments split.
Centromeres, BED
chr start end
One line per chromosome.
Structural variants, VCF
standard VCF, bgzip
See the next section.

The 10 column loop files of 3D-GNOME 2.0 and 3.0, with motif orientations and the factor in the loop file, are not read. Move the orientations to the anchors file and write one loop file per factor.
To convert a .mcool map yourself, run prep_singletons.py from the gnome3d-ng repository. It writes intra chromosomal bin pairs at a chosen bin size and can thin a deep map.
Structural variants
Upload a VCF compressed with bgzip. A record needs SVTYPE of DEL, INS or INV in its INFO field, and END or SVLEN. An insertion uses its ALT sequence when it has one. CTCF motifs in that sequence can become new anchors. The result page counts the skipped records of other types. A phased genotype puts each allele on its own haplotype.
#CHROM  POS       ID    REF  ALT    QUAL  FILTER  INFO                       FORMAT  HG00733
chr1    12101200  del1  N    <DEL>  .     PASS    SVTYPE=DEL;END=12118400    GT      0|1
chr1    12255010  ins1  N    <INS>  .     PASS    SVTYPE=INS;SVLEN=310       GT      1|1
chr1    12390500  inv1  N    <INV>  .     PASS    SVTYPE=INV;END=12402750    GT      1|0
An uploaded file and everything built from it are private, reachable only through the job's link, and deleted after 14 days.
Reading the results
Bead unit
One bead unit is the target distance between two beads 1 kb apart, which is also the bond length. You can compare distances within a job and between jobs of one cell type.
Genes missing from the table
The TSS or the nearest enhancer is more than 5 kb from every bead. Beads exist only in stretches with loops.
Differences between structures
Each structure starts from a different random position. Parts of the region with many loops are similar across structures. Parts with few loops vary more.
Questions
Hi-C instead of ChIA-PET
You can call loops from Hi-C and upload them as your own loops, with the Hi-C as the contact background. Loops called from Hi-C are noisier than ChIA-PET loops, and structures built from them are noisier too.
HiCDiffusion warning
HiCDiffusion was trained on GM12878. For other cell types its predicted map is outside its training data.
Job run time
Run time grows with the size of the region and the number of structures. A job waits in the queue while the GPUs are busy, and the job page shows its place in the queue.
Running gnome3d-ng yourself
The server runs the gnome3d-ng Python package. The package runs on a CPU and uses a GPU when one is present. A run reads one config.ini. The settings reference lists every key with its default, the value on this server and its meaning.
pip install gnome3d-ng
gnome3d-ng --config config.ini --region chr1:11500000-12600000 -n 10 --out models/
