# Design exports

Every screen of web/design/site.pen as a PNG at 1440 px wide, as HTML from Pencil's export, and
as plain text, one string per line in document order. The builds read these when the design
file is not open. A change to the design is exported again, one screen per Pencil call, and the
text files are rewritten with `python web/design/design_text.py web/design/exports`.
